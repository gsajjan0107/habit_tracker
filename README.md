# Habit Tracker

A command-line habit tracking app built in Python to track daily habits, streaks, and progress.

## Features

- Add / remove habits
- Mark habits complete
- Track streaks
- View statistics
- Data saved locally
- Input validation
- Backup recovery for corrupted data

## Tech Used

- Python
- JSON storage
- datetime module

## How to Run

1. Clone repo
2. Run main.py

## Project Structure

main.py  
habits.py  
stats.py  
storage.py  
validators.py  
utils.py
